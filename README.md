
# 游戏商城 (Game Store)

欢迎来到 游戏商城 (Game Store)，这是一个基于 Flask 框架开发的在线游戏平台，用户可以在这里浏览、购买并试玩各种有趣的游戏。项目集成了用户认证、个人资料管理、购买历史记录以及多款游戏的集成，旨在为用户提供一个全面的游戏体验平台。

## 功能

- 用户认证
- - 用户注册、登录和注销功能。
- - 密码哈希存储，确保安全性。

- 用户个人资料
- -  查看和编辑个人信息，包括用户名、邮箱、地址、电话、会员等级和个人头像。
- - 管理收藏的游戏和查看购买历史记录。
- 游戏商城

浏览所有游戏，查看游戏详情，包括封面图、价格、描述和评论。
发表评论，分享游戏体验。
游戏试玩

多款集成游戏，如《Life in Digua》、《Airplane Battle》、《Star Wars》和《Snake》等。
每款游戏都有独立的播放页面，内置音频和图形资源。
管理员功能

（可选）管理游戏列表、用户信息和评论。

## 项目结构


- `app.py`：Flask 应用的主文件，定义了路由和视图函数。
- `static/`：存放静态文件，如图片和 CSS 文件。
  - `mario.jpg`、`plane.jpg`、`snake.jpg`：游戏封面图片。
  - `styles.css`：CSS 样式文件。
- `templates/`：存放 HTML 模板文件。
  - `base.html`：基础模板，包含导航栏和页脚。
  - `home.html`：首页模板，展示热门游戏、最新发布和畅销游戏。
  - `store.html`：商店页面模板，展示所有游戏。
  - `game_detail.html`：游戏详情页面模板，显示游戏的详细信息。
  - `user.html`：用户主页模板，显示用户信息和购买历史。
- `README.md`：项目说明文件。

## 预期效果

### 首页

- 顶部导航栏包含 Logo、商店链接和用户菜单。
- 中部展示热门游戏、最新发布和畅销游戏，每个游戏以卡片形式展示，包含封面图、名称和价格。
- 底部页脚显示版权信息和链接。

### 商店页面

- 左侧过滤栏（未来可扩展）。
- 右侧游戏列表，网格布局显示游戏封面、名称和价格。

### 游戏详情页面

- 显示游戏封面、名称、价格和详细描述。
- 包含截图和评论区（未来可扩展）。

### 用户主页

- 显示用户信息，包括用户名、邮箱、会员时间和收藏游戏。
- 显示用户的购买历史。
- 包含操作按钮，如登出、浏览商店和返回首页。
